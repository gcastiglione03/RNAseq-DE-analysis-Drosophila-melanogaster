# Bulk RNA-seq Differential Expression Analysis — *Drosophila melanogaster*

Differential expression analysis pipeline for a bulk RNA-seq dataset comparing *Drosophila melanogaster* populations (Maine vs. Panama) acclimated at two temperatures (high vs. low), using `limma`-`voom` with sample quality weights.

## Data

Raw/intermediate data files are not version-controlled (excluded via `.gitignore`, ~22 GB). To reproduce the analysis, place the following two files in a local `Data/` folder:

- `salmon.merged.gene_counts.tsv` — gene-level abundance matrix (Salmon output, merged)
- `dme_elev_samples.tsv` — sample metadata (population, temperature)

## Workflow

1. **Load data** — gene-level count matrix and sample metadata; build a `pop_temp` grouping variable (population × temperature).
2. **Build `DGEList`** and verify library sizes.
3. **Filter lowly expressed genes** with `edgeR::filterByExpr()`.
4. **TMM normalization** (`calcNormFactors`).
5. **QC** — MDS plot to check for outliers/sample mislabeling.
6. **`voom` transformation**, with and without sample quality weights (`voomWithQualityWeights`).
7. **Differential expression testing** via `lmFit` + `eBayes`, across four designs:
   - Single factor: temperature only
   - Two-factor: population + temperature
   - Subset: Panama samples only (high vs. low temperature)
   - Contrast matrix: population-specific temperature effects + population×temperature interaction (`Mlowhi`, `Plowhi`, `Diff`)
8. **Export** — result tables (CSV/XLSX) and diagnostic plots (PDF) to `Outputs/`.

## Outputs

| File | Description |
|---|---|
| `voom_plot.pdf`, `voom_qualityweights*.pdf` | Mean-variance trend plots for each design |
| `mds_plot_outliers.pdf` | Sample-level MDS/PCA for QC |
| `dirty_volcano_plot.pdf` | Volcano plot, single-factor model |
| `DEtest__contrast_summary_venn.pdf` | Venn diagram of DE genes across contrasts |
| `topTable_all_genes*.csv/.xlsx` | Full DE result tables per model |
| `results_merge_contrast.csv/.xlsx` | Merged results across the three contrasts (Maine, Panama, interaction) |
